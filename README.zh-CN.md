# Mac Video Player

> 一款简洁的原生 macOS 本地视频播放器，支持标签、播放列表和熟悉的键盘操作。

[English](README.md) · [简体中文](README.zh-CN.md)

<p align="center">
  <img src="./docs/images/welcome-zh-CN.jpeg" alt="Mac Video Player 中文界面" width="100%">
</p>

Mac Video Player 专注于简单的本地播放流程：打开视频或文件夹，浏览自动生成的播放列表，使用标签整理内容，全程不修改原始媒体文件。

## 功能亮点

- **简洁浅色界面**：采用接近 macOS 原生的视觉风格，提供宽大的视频画面和圆形播放/暂停按钮。
- **本地视频库**：支持打开 MP4、MOV、M4V 和 MKV 文件，也可扫描文件夹并自动生成播放列表。
- **可折叠播放列表**：每项显示视频格式和文件大小；通过侧边栏按钮收起播放列表，为视频腾出更多空间，重新展开后仍会保留当前选择。
- **播放进度记忆**：切换视频或退出后自动保存进度，再次打开时继续播放；接近结尾的视频从头开始。
- **播放列表搜索**：按文件名即时搜索，可与标签筛选同时使用；搜索只改变列表显示，上一首和下一首仍按标签筛选后的列表导航。
- **本地标签**：可在播放器或标签编辑页添加、删除和筛选标签。标签单独保存为 JSON，不会写入或修改视频文件。
- **中英文界面**：在 **Mac Video Player > 设置…** 中选择 **English** 或 **简体中文**；切换立即生效并会被记住。
- **播放速度**：可选择 0.5×、1×、1.5× 或 2×，切换视频时保留当前速度。
- **播放控制**：支持顺序播放、随机播放、进度跳转、音量、上一个/下一个、拖入视频、在 Finder 中显示和截取画面。
- **播放错误不打断操作**：文件损坏、无法读取或无法解码时，仅在播放器内短暂显示提示，不弹出确认窗口；仍可继续切换视频和使用快捷键，悬停提示可查看详细原因。
- **视频截图**：点击顶部的 **截图** 按钮或按 `⌘⇧S`，将当前视频帧保存为 PNG；播放和暂停时均可使用，支持自定义快捷键。
- **片段截取**：通过滑块、精确时间输入或当前播放位置选择起点和终点，将片段另存为 MP4，支持取消导出。
- **方向键长按加速**：左右方向键每次跳转 5 秒；持续按住超过 5 秒后，每次重复跳转增加 150%，即每次跳转 12.5 秒。

打开 **Mac Video Player > 设置…**，选择 **English** 或 **简体中文**，点击 **完成** 即可。菜单、播放器控件、播放列表、标签控件和提示会立即更新。

## 快捷操作

| 操作 | 功能 |
| --- | --- |
| `空格` | 播放或暂停 |
| `⌘⌥−` / `⌘⌥=` | 降低 / 提高播放速度 |
| `⌘⌥0` | 恢复 1× 播放速度 |
| `⌘⇧S` | 截取当前视频画面 |
| `⌘⇧E` | 进入或退出片段截取模式 |
| 截取模式中按 `I` / `O` | 将当前播放位置设为起点 / 终点 |
| 截取模式中按 `Esc` | 退出截取模式 |
| `上方向键` / `下方向键` | 上一个或下一个视频 |
| `左方向键` / `右方向键` | 向后或向前跳转 5 秒 |
| 持续按住 `左方向键` / `右方向键` 超过 5 秒 | 每次重复按键跳转 12.5 秒 |
| 在视频区域滚动 | 切换上一个或下一个视频 |
| 在音量滑块上滚动 | 调节音量 |

播放列表区域保持正常滚动。点击播放器右上角的侧边栏按钮即可收起或重新打开播放列表。

截图默认直接保存在 **下载**（`~/Downloads/`），保存成功后会显示提示。在 **Mac Video Player > 设置… > 截图保存位置** 中可选择其他文件夹，或恢复到下载文件夹；修改立即生效，并会在重启后保留。也可使用 **文件 > 截取画面**；在 **Mac Video Player > 截图快捷键…** 中可以修改快捷键或恢复默认值。快捷键仅在播放器激活时有效，截图按钮的提示会显示当前快捷键。

## 视频片段截取

打开视频后，点击顶部 **截取片段** 或按 `⌘⇧E`，进入主播放器内的 **截取模式**。播放会暂停，进度条变为带两个蓝色拖柄的时间轴：拖动左端设置起点，拖动右端设置终点，蓝色区间即导出范围；点击或拖动轨道中间可定位画面。拖动时直接在视频区域预览，松开后精确定位，不需要在独立窗口和播放器之间切换。

下方显示起点、终点和片段时长，可以输入 `HH:MM:SS.mmm`、`MM:SS.mmm` 或秒数精调。也可先定位画面，再点击 **设为起点** / **设为终点**（`I` / `O`）。点击 **预览片段** 或按空格，从起点播放并在终点暂停；拖到视频末尾会停留在当前视频。点击 **退出截取**、按 `Esc` 或再次按 `⌘⇧E` 恢复普通播放界面。时间输入框编辑时按 Return 提交；退出前若仍在编辑，先结束输入。

点击 **导出 MP4…** 选择文件名和保存位置（默认打开“下载”文件夹），任务会在后台排队执行。导出任务面板显示每个任务的进度，支持取消任务和在 Finder 中显示完成的文件；也可通过 **文件 > 导出任务** 重新打开。切换视频或退出截取模式不会取消任务，每个任务使用提交时选定的视频和时间范围。程序不会覆盖原视频，失败或取消时会清理临时输出并保留原有目标文件。退出应用时会先取消未完成的任务。

应用已内置独立的 FFmpeg，将视频编码为 H.264、音频编码为 AAC，并支持 MKV 等播放格式。FFmpeg 和 x264 编码库静态打包，复制完整应用到其他兼容的 Mac 后即可截取片段，无需安装 FFmpeg 或 Homebrew。当前应用包适用于 Apple Silicon（arm64）、macOS 13.0 或更高版本。

## 标签

在 **添加标签** 输入框中键入标签后按 Return，或点击 **添加**。即使播放状态更新、正在使用输入法组合文字，输入框仍可持续编辑。选择播放列表筛选器中的标签，即可只显示匹配的视频。

标签保存在：

```text
~/Library/Application Support/MacVideoPlayer/tags.json
```

## 构建

### 环境要求

- macOS 13.0 或更高版本
- Swift 6 和 macOS Command Line Tools
- `Vendor/IINAFrameworks` 中的 IINA/libmpv 运行库
- `Vendor/FFmpeg/bin/ffmpeg` 中的独立 FFmpeg（源码、许可证和构建记录同目录提供）

如果仓库中没有运行库，请先安装 IINA，再导入其 Frameworks 目录：

```sh
./scripts/fetch-iina-runtime.sh
```

如果 IINA 安装在 `/Applications/IINA.app` 以外的位置，可以设置 `IINA_APP`：

```sh
IINA_APP="/path/to/IINA.app" ./scripts/fetch-iina-runtime.sh
```

仓库内置的 FFmpeg 可以直接打包。需要从所附源码重新构建时运行以下命令；该步骤只在项目目录内构建，不会安装到系统，也不需要 Homebrew：

```sh
python3 scripts/build-ffmpeg-runtime.py --jobs 4
```

构建应用包（会检查 FFmpeg 的架构、macOS 最低版本、编码器以及外部动态库依赖）：

```sh
./scripts/build-app.sh
```

构建结果位于 `build/MacVideoPlayer.app`。创建 DMG 安装镜像：

```sh
./scripts/build-dmg.sh
```

若受限环境无法生成调试符号，可使用 `APP_DEBUG_INFO_FORMAT=none ./scripts/build-app.sh` 构建应用。

## 验证

如环境提供 XCTest，可运行：

```sh
swift test
```

仅安装 Command Line Tools 时，可运行核心回归检查：

```sh
python3 scripts/test-regressions.py
```

检查覆盖语言保存、标签输入和输入法行为、播放列表筛选和排序、方向键长按加速、播放事件、命令串行化、截图路径和干净的 DMG 暂存流程，不会打开播放器窗口或解码媒体。

性能回归还覆盖后台标签写入、并发编辑和失败恢复、跳过未变化的保存、排序缓存、扫描取消、扫描期间删除文件以及暂停时的进度更新。若环境无法提供 OpenGL 像素格式，脚本会明确跳过隐藏窗口的输入检查，其余核心检查继续执行。

片段导出回归使用模拟编码器，覆盖时间输入、起止范围、导出参数、取消、原视频保护、已有文件保护、失败重试和临时文件清理，不处理真实媒体。
检查还验证内置编码器优先、应用移动后的定位、空 PATH，以及内置工具丢失或不可执行时不依赖本机 FFmpeg。

构建后可验证完整应用中的实际片段导出。脚本会复制并重命名应用，在不含 Homebrew 的 PATH 下使用微小合成视频检查 MP4/MKV、音轨和起止位置，不打开播放器窗口：

```sh
python3 scripts/test-bundled-ffmpeg.py
```

检查还覆盖播放事件突发时的合并调度、自然排序结果以及标签汇总去重。运行不启动播放器的扫描和标签基准测试：

```sh
python3 scripts/benchmark-performance.py
```

基准测试使用临时文件和合成标签，报告五次测量的中位耗时，不解码媒体。优化前后数据和测量范围见 [性能记录](docs/performance.md)。

## 运行库与许可证

应用包包含 IINA/libmpv、独立 FFmpeg/x264 和相关媒体依赖。播放时直接解码原始文件，在系统支持时使用硬件解码；片段导出使用应用内置的独立工具，将所选范围写入新的 MP4 文件。FFmpeg 对应源码、许可证和构建步骤位于应用包的 `Contents/Resources/FFmpeg`。
